# starter-files

El código con el que empieza cada lección: es lo que el estudiante ve al abrir el enlace de **Práctica** del [plan del curso](../course-plan.md).

Una carpeta por lección (`leccion-01/`, `leccion-02/`, …), cada una con `index.html` y, desde la lección 4, `styles.css`. El mismo código va precargado en el pen de CodePen de esa lección.
