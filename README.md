# Fundamentos de Desarrollo Web: HTML y CSS

Curso en video de unos 60 minutos para estudiantes de secundaria (12 a 17 años) que nunca han programado. Aprenderás qué es un sitio web, cómo se construye una página con HTML y cómo darle estilo con CSS, hasta crear tu propia página de perfil.

**No necesitas instalar nada.** Todo se hace desde el navegador (Chrome, Firefox, Safari o Edge), en editores en línea y gratuitos como [CodePen](https://codepen.io), [JSFiddle](https://jsfiddle.net) o [Replit](https://replit.com).

📄 **Plan del curso:** [course-plan.md](course-plan.md), con todas las lecciones, sus videos y los enlaces para practicar.

## Cómo usar este repositorio

1. Abre el [plan del curso](course-plan.md) y mira la lección en YouTube.
2. Haz clic en el enlace **Práctica** de la lección: se abre el editor en línea con el código inicial ya cargado.
3. Si te trabas, compara tu trabajo con el ejemplo terminado de la carpeta `completed-examples/`.

Si prefieres trabajar con los archivos de este repositorio, copia el contenido del `.html` y del `.css` de la lección en un pen nuevo de CodePen, en los paneles HTML y CSS.

## Estructura

| Carpeta | Qué contiene |
|---|---|
| [`starter-files/`](starter-files/) | El código con el que empieza cada lección (lo que ves al abrir el enlace de práctica) |
| [`completed-examples/`](completed-examples/) | El resultado al terminar cada lección |
| [`scripts/`](scripts/) | Los guiones de los videos: qué se dice y qué se muestra en pantalla |

Dentro de cada carpeta hay una subcarpeta por lección: `leccion-01`, `leccion-02`, etc.

## Contribuir (equipo)

- Rama principal: `main`. Se trabaja en `develop` y en ramas `feature/leccion-NN-tema`, que se unen a `develop` con pull request.
- Mensajes de commit en inglés con [Conventional Commits](https://www.conventionalcommits.org/) (por ejemplo, `feat(lesson-02): add starter html page`).
- Sin nombres de autores ni logos en el código ni en los videos: los créditos van solo en la sección «Elaboración» de `course-plan.md`.
