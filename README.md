# Plan de curso: Fundamentos de Desarrollo Web

## Resumen del curso

Este curso de **1 hora** introduce a estudiantes de secundaria a la creación de sitios web sencillos con HTML y CSS. **¡No requiere descargas!** Solo abre tu navegador web.

| Información | Detalle |
|---|---|
| **Duración total** | ~60 minutos (6 lecciones) |
| **Público objetivo** | Estudiantes de 12 a 17 años sin experiencia en programación |
| **Prerrequisitos** | Ninguno |
| **Herramientas necesarias** | ¡Solo tu navegador web! (Chrome, Firefox, Safari, Edge) |
| **Plataformas** | 100 % en línea y gratuitas |
| **Enfoque** | HTML y CSS, con un proyecto final: tu página de perfil |

## Secuencia de lecciones

### Lección 1: ¿Qué es un sitio web? (5 minutos)

- **Descripción**: Descubre qué es un sitio web, cómo llega una página a tu pantalla y para qué sirven HTML y CSS.
- **Consejos clave**: Un sitio web es un conjunto de páginas conectadas por enlaces; HTML define el contenido y la estructura, y CSS, la presentación.

### Lección 2: Tu primera página HTML (10 minutos)

- **Descripción**: Conoce las etiquetas, los elementos y los atributos, y escribe tu primera página con títulos y párrafos.

## Instrucciones de configuración

### Para estudiantes

No hay nada que instalar: solo necesitas un navegador web y conexión a internet.

1. **Mira el video** de la lección en YouTube.
2. **Abre la práctica en línea**: el enlace de cada lección abre JSFiddle con el código inicial ya precargado. No necesitas registrarte.
3. **Escribe en los paneles HTML y CSS**: en el panel HTML va solo lo que está dentro de `<body>`, porque JSFiddle prepara el resto del documento. El panel de JavaScript no se usa en este curso.
4. **Ejecuta con Run** (o `Ctrl + Enter`) y mira el resultado en el panel *Result*.
5. **Haz la práctica** de la pausa de cada lección y compara tu código con el código terminado.

### Para generar el PDF del plan de curso

El PDF se genera desde este `README.md` con **Pandoc** y el motor **WeasyPrint**. La configuración está en `pandoc/course-plan.yaml` y el diseño en `pandoc/course-plan.css`.

1. **Instala Pandoc.** En Windows: `winget install --id JohnMacFarlane.Pandoc -e`. En macOS: `brew install pandoc`.
2. **Instala WeasyPrint.** En Windows, descarga `weasyprint-windows-onefile.zip` de sus [releases oficiales](https://github.com/Kozea/WeasyPrint/releases) y agrega al `PATH` la carpeta que contiene `weasyprint.exe`. En macOS: `brew install weasyprint`.
3. **Genera el PDF** desde la raíz del repositorio:

```bash
pandoc --defaults=pandoc/course-plan.yaml
```

El archivo queda en `build/upc-pre-202620-1asi0730-8130-IngesCompanyCC-course-plan.pdf`, con el nombre que pide el enunciado. La carpeta `build/` no se sube al repositorio.
