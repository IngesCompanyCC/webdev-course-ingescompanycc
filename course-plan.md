# Fundamentos de Desarrollo Web

## Resumen del Curso

Este curso de 1 hora introduce a estudiantes de secundaria a la creación de sitios web sencillos con HTML y CSS. **¡No requiere descargas!** Solo abre tu navegador web.

**Duración total**: ~60 minutos
**Público objetivo**: Estudiantes de 12 a 17 años sin experiencia en programación
**Prerrequisitos**: Ninguno
**Herramientas necesarias**: **¡Solo tu navegador web!** (Chrome, Firefox, Safari, Edge)

**📁 Repositorio de código fuente**: [https://github.com/IngesCompanyCC/webdev-course-ingescompanycc](https://github.com/IngesCompanyCC/webdev-course-ingescompanycc)

## Secuencia de la lección

### Lección 1: ¿Qué es un sitio web? (5 minutos)
- **Descripción**: Descubre de qué están hechas las páginas que visitas todos los días y por qué HTML y CSS son sus piezas básicas.
- **Enlace**: [Ver la lección](TODO-youtube)
- **Consejos clave**: Sitio web = Contenido (HTML) + Estilo (CSS).
- **Empieza a programar**: [Abrir CodePen](TODO-codepen)

### Lección 2: Tu primera página HTML (10 minutos)
- **Descripción**: Conoce las etiquetas, los elementos y los atributos, y crea tu primera página.
- **Enlace**: [Ver la lección](TODO-youtube)
- **Consejos clave**: Usa `<html>`, `<head>`, `<body>`, `<h1>` y `<p>`.
- **Práctica**: [Clic para programar](TODO-codepen) 👈 **¡No necesitas registrarte!**

### Lección 3: Listas, imágenes y enlaces (10 minutos)
- **Descripción**: Agrega listas, imágenes y enlaces para que tu página tenga más contenido.
- **Enlace**: [Ver la lección](TODO-youtube)
- **Consejos clave**: Usa las etiquetas `<ul>`, `<li>`, `<img>` y `<a>`.
- **Práctica**: [Clic para programar](TODO-codepen) 👈 **¡Comienza al instante!**

### Lección 4: Introducción a CSS (12 minutos)
- **Descripción**: Dale estilo a tu HTML con selectores, colores y fuentes.
- **Enlace**: [Ver la lección](TODO-youtube)
- **Consejos clave**: Un selector elige qué cambiar; por ejemplo, `body { background-color: lightblue; }`.
- **Práctica**: [Aplicar estilo con un clic](TODO-codepen) 👈 **¡No es necesario registrarse!**

### Lección 5: Proyecto: tu página de perfil (15 minutos)
- **Descripción**: Combina HTML y CSS para crear una página de perfil personal: centra el contenido y agrega colores y bordes.
- **Enlace**: [Ver la lección](TODO-youtube)
- **Consejos clave**: Centrar con `margin: 0 auto;`, bordes con `border` y esquinas redondeadas con `border-radius`.
- **Proyecto Final**: [Crea tu Perfil](TODO-codepen) 👈 **¡Guarda y comparte!**

### Lección 6: Errores comunes y próximos pasos (8 minutos)
- **Descripción**: Los errores más comunes de quien empieza, cómo encontrarlos y dónde seguir aprendiendo.
- **Enlace**: [Ver la lección](TODO-youtube)
- **Consejos clave**: Cierra tus etiquetas, revisa los `;` y las `{}` en CSS, y valida tu código. Sigue aprendiendo con [MDN Web Docs](https://developer.mozilla.org/es/).
- **Comparte tu Trabajo**: [Envía tu Creación](TODO-formulario)
